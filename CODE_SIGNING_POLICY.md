# Code Signing Policy for SCLOC-Verse

## Publisher

SCLOC-Verse binaries are signed by **SignPath.io** using a code signing certificate issued by **SignPath Foundation**.

```
Free code signing provided by SignPath.io, certificate by SignPath Foundation.
```

## What is signed

The following artifacts are signed after they are built from the source code in this repository:

- `SCLOCVerse.exe`
- `SCLOC-Verse_Setup.exe`

All signed binaries are built in a verifiable, automated build process from the source code available at:
https://github.com/Vova-Bob/SCLOC-Verse
