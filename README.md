# SCLOC-Verse — Official Release Hub

> Ukrainian localization, voice assistant, and observability platform for Star Citizen.

## About this repository

Active development is now performed in a private repository.
This repository remains the official Release Hub for SCLOC-Verse.

It contains only release artifacts — installers, changelogs, and documentation.

## What lives here

- **Releases** — signed Windows installers (`SCLOC-Verse_Setup.exe`) and checksums
- **Changelog** — release notes per version
- **Documentation** — privacy, security, licensing
- **Issue Tracker** — bug reports and feature requests

## Download the latest version

[Latest Release](https://github.com/Vova-Bob/SCLOC-Verse/releases/latest) — download `SCLOC-Verse_Setup.exe`.

The app updates itself automatically. To update manually, download and run the latest Setup.

## Update channels

- **Стабільний (Stable)** — recommended for all users
- **Тестовий (Dev)** — pre-release builds for testers
