Hotfix-випуск. Виправлено критичну production-проблему — нескінченний шторм 401-помилок.

## 🔧 Виправлення

### ⚡ Телеметрія

Виправлено нескінченний цикл повторних запитів, який виникав після завершення терміну дії авторизаційної сесії.

Коли access token прострочувався, кожна спроба відправки телеметрії отримувала HTTP 401. Події поверталися в чергу і повторно відправлялися кожні 30 секунд, створюючи безперервний потік rejected-запитів до бази даних.

Після оновлення події, відхилені з HTTP 401, більше не повертаються в чергу. Поведінка повторних спроб для тимчасових помилок (мережеві помилки, 5xx) залишається без змін.
