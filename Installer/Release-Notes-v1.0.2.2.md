Hotfix-випуск. Виправлено нескінченний цикл 401-запитів до сервера.

## 🔧 Виправлення

### ⚡ Телеметрія

Виправлено критичну помилку, яка призводила до безперервного потоку HTTP 401-запитів до бази даних.

Після завершення терміну дії авторизаційного токена клієнт продовжував надсилати події телеметрії кожні 30 секунд. Сервер відхиляв їх із HTTP 401, але клієнт повертав відхилені події назад у чергу й повторював відправку — нескінченний цикл.

Після оновлення події, відхилені з HTTP 401, більше не повертаються в чергу. Цикл припиняється після першої невдалої спроби. Поведінка для тимчасових помилок (мережеві збої, HTTP 5xx) не змінена — вони продовжують повторно відправлятися.
