# SCLOC-Verse v1.0.2.4

Hotfix-випуск. Виправлено критичну помилку інсталятора v1.0.2.3, який вимагав встановлення .NET 9 runtime.

## 🔧 Виправлення

### Інсталятор

- **Відновлено self-contained публікацію** — інсталятор v1.0.2.3 було зібрано як framework-dependent, тому при першому запуску на комп'ютерах без глобально встановленого .NET 9 з'являлося вікно "You must install or update .NET".
- **Скрипт збірки тепер завжди очищає publish-директорію** — запобігає змішуванню файлів між framework-dependent (Debug) та self-contained (Release) білдами.
- **Додано явний прапорець `-p:SelfContained=true`** у виклик `dotnet publish` для гарантованого self-contained білду.

## ✨ Нове

### Overlay Hangar Timer

- **Спрощений вигляд (EX-Hangar)** — додано компактний горизонтальний бейдж як альтернативу класичному накладанню. Містить лише 5 LED-індикаторів фаз і таймер.
- **Перемикання вигляду** — Settings Hub → Overlay → "Вигляд": Класичний / Спрощений.
- **Live-preview** — перемикання застосовується до відкритого overlay негайно.
- **Zero Regression** — класичне вікно збережено без змін; default = Класичний.
