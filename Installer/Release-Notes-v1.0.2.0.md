# SCLOC-Verse v1.0.2.0 — Stable Release

Stable-реліз. 68 комітів після v1.0.1.0: три нові модулі (Auto Key, Anti-AFK міграція, Foreground Gate), перероблений Overlay Settings, динамічні підказки гарячих клавіш, десятки UI-покращень та bugfix'ів.

---

## Нове

**Auto Key — модуль авто-натискання клавіші**
Незалежний модуль, що періодично натискає обрану клавішу з настроюваним інтервалом (100–2000 мс). Три стани (Вимкнено / Працює / Пауза), індикатор-бейдж «● Auto Key» поверх гри, гаряча клавіша Home (призначувана). State­less foreground-гейт за PID процесу — Auto Key активний лише коли на передньому плані Star Citizen.

**Anti-AFK — міграція в SCLOC-Verse**
Анти-AFK перенесено з WinForms-версії в основний застосунок (WPF/.NET 9). Замість глобальних low-level hooks (WH_KEYBOARD_LL/WH_MOUSE_LL) тепер використовується один PInvoke `GetLastInputInfo` — усунуто always-on keylogger-поведінку. Пульсуючий індикатор-overlay (5 позицій, 2 анімації), гаряча клавіша End (призначувана), налаштування кольору, розміру, режиму показу.

**Foreground Gate — спільний гейт видимості**
Виділено stateless-хелпер `StarCitizenForeground.IsStarCitizenForeground()`. Індикатори Auto Key та Anti-AFK показуються лише коли активне вікно Star Citizen. Alt+Tab / браузер / Discord → індикатори зникають, SendInput призупиняється. Повернення у гру → усе відновлюється.

**Settings Hub — Phase 0.5 + Overlay**
Центр керування налаштуваннями з дизайн-системою (єдині стилі карток, ComboBox, слайдерів). Overlay-налаштування з live-preview, jump-to-click слайдери, drag → синхронізація позиції, reset позиції.

**Динамічні підказки гарячих клавіш**
Підказки з комбінаціями гарячих клавіш тепер будуються з актуальних призначень (SSOT) — більше не брешуть після rebind у «Гарячих клавішах».

---

## Покращення

**Картка Anti-AFK — три стани**
Картка тепер показує 3 стани симетрично Auto Key: 🟢 працює (увімкнено + активна Star Citizen), 🟡 очікує Star Citizen (увімкнено, але гра не активна), ⚫ вимкнено.

**Reset усіх накладань**
Кнопка «↺ Скинути всі накладання» скидає Hangar Timer + Anti-AFK + Auto Key до заводських значень однією дією.

**Єдиний стиль ComboBox**
Усі ComboBox у Settings Hub використовують єдиний стиль `HubComboBox` (темна тема, hover, dropdown) — прибрано дублювання стилів (DRY).

**Локалізація Overlay**
UI повністю українською: НАКЛАДАННЯ (вместо OVERLAY), Пульсація / Плавна пульсація, Постійно / Лише під час спрацювання, «накладання» в усіх текстах.

**Вирівнювання Overlay Settings**
Симетричні відступи, два типи рядків (slider / combo), прибрано фіксовані ширини TextBlock — компонування стабільне на будь-якій довжині тексту.

## Виправлення

**Auto Key: SendInput не надсилав натискання (ERROR_INVALID_PARAMETER)**
Keyboard-only union давав INPUT=32 байти, тоді как `sizeof(INPUT)=40` на x64. `SendInput` відхиляв `cbSize` з помилкою 87 — натискання не надсилались. Виправлено канонічним Win32 ABI (InputUnion з MOUSEINPUT визначає коректний розмір). Після фіксу `SendInput` повертає 2 (обидва інпути прийнято).

**Overlay: другий слайдер блокувався**
`CaptureMouse()` без `ReleaseMouseCapture()` захоплював мишу на першому слайдері — другий не реагував на кліки. Прибрано `CaptureMouse` зовсім: клік = стрибок значення, подальший drag через Thumb штатно.

**Overlay: клік по треку не стрибав до позиції курсора**
WPF Slider виконував LargeChange (дефолт 1.0) замість стрибка до курсора. `PreviewMouseLeftButtonDown` тепер обчислює точне значення з X-позиції курсора відносно Track.

**Гарячі клавіші Anti-AFK потрапляли в картку Hangar Timer**
`ResolveGroup` мав fallback «Hangar Timer · цикл» для нерозпізнаних ID. Тепер `AntiAfk.*` розпізнається → окрема картка Anti-AFK.
