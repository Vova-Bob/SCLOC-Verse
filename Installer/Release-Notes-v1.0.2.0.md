## ✨ Що нового

### 🎮 Auto Key

Новий інструмент для автоматичного натискання обраної клавіші.
Ідеально підходить для автоматичного приймання запрошень та місій у Star Citizen.
Працює лише тоді, коли активне вікно Star Citizen.

### 🛡️ Anti-AFK

Повністю інтегрований у SCLOC-Verse.
Захищає від AFK без використання глобальних хуків.
Також працює лише під час активної гри.

### ⚙️ Новий центр налаштувань

Повністю оновлений розділ налаштувань.
Усі параметри згруповані та стали значно зручнішими.

Є перевірка конфліктів та швидке скидання до стандартних значень.

### 🎨 Покращений Overlay

Живий перегляд усіх змін.
